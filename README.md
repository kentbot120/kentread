# KentRead

KentRead 是一个 KOReader 的 AI 辅助阅读插件。在墨水屏上读长书或专业书时，常会遇到读不进去、概念卡壳或需要查资料的情况。这个插件让你在阅读器内直接看全书导读、按不同风格改写章节、划词解释概念或联网检索，看完随时切回原文。

功能包括：
- 全书介绍：提取正文生成导读，理清结构脉络与章节指引。
- 章节改写：按章节切换不同的叙述风格（如费曼讲法、海明威风格等）。
- 划词解释：选中词句后附带前后约 300 字上下文发给模型解释。
- 联网搜索：选中词句调用 DeepSeek Search 查网页摘要和来源。
- 写作动画：等待模型输出时展示对应作家的定格书写动画。
- 手机扫码配置：在手机浏览器粘贴 API Key，避免在阅读器上逐字输入。
- 本地保存：生成内容跟随书籍目录保存，支持离线阅读。

## 阅读与搜索

### 全书介绍

提取全书正文生成 1000–1800 字的导读，梳理核心论题、各部分推进逻辑和阅读重点。

导读中的来源链接可直接跳回原书对应章节。生成提示词要求小说避免泄露结局和关键反转，但模型输出可能偶有例外。

### 章节改写

默认改写当前阅读章节，也可以手动选择其他章节。弹窗中点击「换个读法」可以在同一章节的不同配方间切换，已生成的内容直接打开。

改写提示词以名家写作技法为参照：

| 阅读配方 | 适合什么时候用 | 表达方式 |
| --- | --- | --- |
| 更好懂 · 费曼 | 术语多、推理跳跃，读起来费劲 | 直白表达、具体类比、拆开推理 |
| 更诙谐 · 老舍 | 想换一种轻松些的讲法 | 生活化语言、细节观察、温和幽默 |
| 更简练 · 海明威 | 表达冗长，想读得更干净 | 短句、具体动词、少修饰，保留必要信息 |
| 讲成故事 · 茨威格 | 历史、传记、商业书，概念多而人物少 | 回到具体的人和场景，抓住关键时刻 |
| 问答体 · 柏拉图 | 理论、哲学、教材，推理一环扣一环 | 一问一答，用追问亮出推理 |
| 更犀利 · 王小波 | 社科、观点类，想看清论证要害 | 平实口语、清楚逻辑、冷静反讽 |
| 更有画面 · 汪曾祺 | 小说、散文，想读出场景和细节 | 白描、具体细节、从容节奏 |
| 说书腔 · 单田芳 | 小说、历史，想换成听书的感觉 | 说书人口吻、埋扣子、留悬念 |
| 武侠风 · 金庸 | 小说、历史，想读得更有气势 | 半文半白、人物出场有气度 |
| 讲给孩子 · 郑渊洁 | 难书入门、亲子共读 | 短句、生活经验、具体例子 |

改写逻辑是先理清本章主线与关键事实，再按选定风格重新组织语言，细节尽量取自原文，不做简单逐句替换。「更简练」旨在压缩修辞，不会删减关键论据或情节。所有配方均要求保留事实、人物关系与数据。

作家姓名仅作为表达风格的参考，模型输出内容可能存在偏差或遗漏，请对照原书核对。

### 划词解释 · AI

选中文字后点击「AI 解释」。支持划词操作菜单，以及单词长按打开的词典弹窗（需较新版本 KOReader 支持扩展按钮；旧版请划选文字使用划词菜单）。主菜单无此入口。

- 发送选中文字、前后各约 300 字原文（英文约 150 词）、书名、作者与当前章节名。单次划选超过 1000 字会被拒绝。
- PDF 等固定版面文档仅发送选中文字，不包含前后上下文。
- 采用主模型配置及思考模式。思考深度较高时耗时稍长，期间可展开查看思考过程。
- 结果按「书籍 × 选中文字」缓存。相同文字再次选中时直接展示缓存，点「重新解释」才会结合新上下文重新请求。
- 提示词要求区分上下文推断与通用知识并防剧透，内容仅供参考。

### 联网搜索 · DeepSeek Search

选中文字后点击「联网搜索」，入口同划词解释。

1. 编辑或确认搜索词，最多 128 个 Unicode 字符，支持 `site:` 及引号等搜索语法。
2. 调用官方接口 `POST https://api.deepseek.com/v1/tools/search`。
3. 弹窗展示前 5 条结果的标题、摘要、站点和发布时间。点击来源链接可通过 KOReader 菜单复制、显示二维码或在支持的设备上打开浏览器。

该功能只调用 Search 检索接口，不经由聊天模型总结，也不调用 Fetch 抓取网页。请求仅发送搜索词与选项，不发送书籍信息或正文。

结果按「书籍 × 搜索词」保存在本地并附带时间戳。重新输入相同搜索词可离线查看保存结果，点「联网搜索」或「重新搜索」则发起新请求。搜索调用按官方规则计费，详见 [DeepSeek 搜索文档](https://api-docs.deepseek.com/zh-cn/guides/search/)。出错时不自动重试，防止意外消耗。

### 写作动画

改写请求发出后，在模型返回正文前，弹窗会播放对应作家的定格动画（如海明威、王小波在打字机前敲字，老舍、费曼、茨威格等人提笔书写，单田芳说书）。展开「思考」可切到思考过程，收到正文后自动切为正文。

动画读取 `art/` 目录下的 30 张灰度图（每位作家 3 张），每 0.25 秒局部刷新一次，采用墨水屏快速刷新模式以减少闪烁。插画为 AI 生成的风格示意，与作家本人及其家属无关。

## 快速开始

### 1. 安装插件

将本项目目录复制到阅读器的插件路径：

```text
koreader/plugins/kentread.koplugin/
```

确保 `main.lua`、`_meta.lua`、`setup.html` 和 `art/` 等文件与目录完整位于上述路径下，随后重启 KOReader。

### 2. 手机扫码配置

准备一个设备可访问的 OpenAI 兼容接口、模型名称及 API 密钥。

1. 手机与阅读器连接同一 Wi-Fi。
2. 在 KOReader 中打开一本可重排文字书。
3. 进入 **菜单 → 工具 → KentRead → 扫码配置接口 / 密钥**。
4. 手机扫码打开临时网页，填入接口地址、模型名和 API 密钥。
5. 点击「保存到阅读器」，提示成功后关闭网页。

接口地址需填写根地址，不带末尾的 `/chat/completions`：

| 接口 | 地址示例 | 模型名称 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | 当前示例配置为 `deepseek-flash`，以服务商实际支持为准 |
| OpenAI | `https://api.openai.com/v1` | 填写账号可用的模型名称 |
| 其他兼容服务 | 服务商提供的兼容接口根地址 | 填写对应服务支持的名称 |

联网搜索密钥说明：
- 主接口为官方 `https://api.deepseek.com` 或 `https://api.deepseek.com/v1` 时，可直接复用主密钥。
- 主接口为其他服务时，需在扫码页面展开「联网搜索 · DeepSeek（可选）」，单独填入 DeepSeek API 密钥，主密钥不会外发。
- 单独填写搜索密钥时优先使用；留空则保持原值。搜索接口地址固定为官方端点，不随主接口变化。

配网服务通过局域网 HTTP 传输，没有加密，只在可信网络中使用，公共 Wi-Fi 请改用 USB 配置。数据不经过插件开发者的服务器。二维码里带有临时访问凭据，不要分享。保存成功、手动关闭或 5 分钟超时后服务会自动停止；设备休眠、断网、关书或退出时也会停止。页面不回显已有密钥，留空即保留旧值；若修改接口地址需重新填写密钥。

### 3. 开始阅读

在阅读界面打开 **菜单 → 工具 → KentRead**：

- **全书介绍**：首次生成需确认，生成过直接打开。
- **章节改写**：选择配方；要换章节可点「选择其他章节」。
- **查看生成进度**：重新打开正在生成的弹窗。
- **停止生成**：取消当前任务，已保存的正文不受影响。

正文流式输出并逐步刷新，可展开查看思考过程；搜索任务在接口返回后完整展示。弹窗关闭后后台任务继续运行，完成后弹提示；关闭书籍则中止任务。同一时间只运行一个生成或搜索任务，但可随时浏览已缓存内容。

弹窗内支持调整字号、钉住窗口和重新生成。章节改写支持「查看原文」与「换个读法」；跳回原书后可用 KOReader 自带的返回键回到之前的位置。

可在手势管理中为「KentRead：全书介绍」和「KentRead：章节改写」绑定快捷手势。

## USB 配置与高级参数

也可以通过文件直接配置：复制 [`config.sample.lua`](config.sample.lua) 为 `config.lua`，在电脑上修改后通过 USB 拷入插件目录。

| 参数 | 用途 |
| --- | --- |
| `base_url` | OpenAI 兼容接口根地址 |
| `api_key` | API 密钥 |
| `model` | 接口支持的模型名称 |
| `search_api_key` | 独立 DeepSeek 搜索密钥；留空时仅允许复用官方 DeepSeek 主密钥 |
| `max_tokens` | 模型输出上限，不超过服务商限额 |
| `extra` | 原样合并入请求体的附加参数（如思考模式参数） |

示例默认使用 DeepSeek。若更换其他服务，请核对 `max_tokens` 并清理不兼容的 `extra` 字段。`model`、`max_tokens` 与 `extra` 不用于 Search 请求。

配置生效规则：
- 扫码保存的地址、密钥、模型及搜索密钥优先于 `config.lua`；未建立 `config.lua` 时使用示例配置。
- 高级参数始终从 `config.lua`（或示例文件）读取；若扫码配置的接口与文件不一致，不继承旧接口的 `extra`。
- 扫码配置保存在 KOReader 设置目录的 `kentread.json`，删除该文件即可恢复纯文件配置。`config.lua` 已被 Git 忽略，请勿提交真实密钥。

## 隐私与费用

- 全书介绍发送整本正文；章节改写只发送选定章节，均附带书名和作者。父章节包含其子节；无目录时会提示使用全文。
- 划词解释发送选中文字、前后约 300 字上下文、书名、作者与当前章节名。
- 联网搜索仅发送确认后的搜索词到 DeepSeek 官方接口，不发送原书上下文。
- 内容直接发给你配置的模型服务，不经过插件开发者的服务器。服务商可能记录内容并收费，请自行确认其政策和你对书籍内容的使用权限。
- 配网页面不加载外部资源，已有密钥不回传给浏览器。
- 密钥明文保存在设备设置目录，写入时设为 `0600` 权限。若设备文件系统不支持权限管理，备份或分享设置前需自行清除密钥。
- 生成文本、思考过程、搜索词及网页摘要均保存在本地书籍目录中。分享书籍的 `.sdr` 文件夹前请留意其中包含的缓存。

## 数据与兼容

旧版本生成的 `condensed.html` 和 `fig*.svg` 已不再使用，可手动删除。

生成结果存放在书籍同级 `.sdr/kentread/` 目录下：

```text
intro/content.html                   全书介绍
chapters/0001/clear/content.html      第 1 章节 · 更好懂
chapters/0001/humor/content.html      第 1 章节 · 更诙谐
chapters/0001/concise/content.html    第 1 章节 · 更简练
search/<搜索词的 SHA-256>/content.html  搜索结果
explain/<选中文字的 SHA-256>/content.html  划词解释结果
```

各目录下 `thinking.txt` 用于保存思考过程。章节缓存按目录顺序编号，若书籍排版或目录发生变动，建议重新生成。

## 支持范围与已知限制

- 全书介绍与章节改写支持 EPUB、AZW3、MOBI、FB2、TXT 等可重排格式，不支持 PDF。划词解释与联网搜索支持可划选文字的 PDF，但 PDF 下划词解释没有前后上下文。
- 仅在 Kindle PaperWhite 3 上做过真机测试。代码中包含 Kindle 适配（`lipc-set-prop` 防休眠、`iptables` 临时开端口、针对 REAGL 墨水屏优化的动画刷新）。其他 Kindle、Kobo 等设备尚未测试，欢迎反馈。
- 生成请求依赖系统内的 `/usr/bin/curl`，阅读器需具备网络连接。
- 全书介绍一次性发送全文，本地提取上限设为 3 MB，实际受模型自身上下文窗口限制。
- 章节按目录划分，父章节包含子节，遇到同级或上级目录项截止；无目录时将全文作为一个章节。
- 章节改写篇幅可能较长，触及模型输出上限时会提示「可能不完整」，可调大 `max_tokens` 或改选子章节。
- 暂不支持自动分块、断点续写或网页端自定义配方；任务失败后重试可能产生额外调用费用。
- 自动化测试无法完全替代真机排版、二维码扫码及防火墙环境验证。

## 常见问题

**找不到 KentRead 菜单？**
打开一本书后再查看，插件仅在阅读界面生效。同时检查插件目录是否有多余嵌套层级，并确认重启了 KOReader。

**扫码界面没有二维码？**
若 KOReader 缺少 `QRWidget` 组件，可升级 KOReader，或在手机上手动输入弹窗显示的完整局域网网址。

**手机无法打开配网页面？**
确认两台设备处于同一 Wi-Fi 网络，配网未超时且未手动关闭。访客网络、局域网隔离可能阻断连接，配网依赖 IPv4。若连不上，请通过 USB 文件方式配置。

**划词没有搜索或 AI 解释按钮？**
长按查词会唤出词典弹窗，新版 KOReader 按钮集成在词典界面（Wikipedia 弹窗除外）；旧版请滑动划选文字打开操作菜单。插件主菜单不提供这两个功能。

**搜索提示密钥或余额错误？**
联网搜索必须使用 DeepSeek 官方 API 密钥。HTTP 402 为余额不足，429 为触发限速，处理后手动重试即可。

**接口报错或正文截断？**
核对接口地址、密钥、模型名称以及 `max_tokens`、`extra` 字段。小上下文模型难以承载全书导读，遇到长章节可选择子章节改写。任务中断不会影响已保存的历史内容。

## 开发与测试

配方与提示词定义在 [`kr_prompts.lua`](kr_prompts.lua)。如需添加配方，在 `STYLES` 表中补充 `id`、`title`、`author`、`description` 和 `techniques`，重启后生效。`id` 对应缓存路径，发布后请勿随意变更。

搜索词校验、结果渲染及缓存逻辑见 [`kr_search.lua`](kr_search.lua)；划词校验、上下文截取及提示词构建见 [`kr_explain.lua`](kr_explain.lua)；后台网络传输均走 [`kr_llm.lua`](kr_llm.lua) 中的 curl 封装。

运行自动化测试（无需 KOReader 环境或真实 API Key）：

```sh
uv run --with lupa python tests/run.py
```

测试使用 Lua 5.1 执行插件核心逻辑，模拟 KOReader UI 与系统调用，覆盖章节截取、配方隔离、搜索词 Unicode 校验、密钥隔离、外链安全、JSON 解析、HTTP 拆包及配网生命周期，并结合 Python 的 LuaSocket 适配层对真实 TCP 交互与表单存储进行验证。
