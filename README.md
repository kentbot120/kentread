# KentRead

> 同一本书，不同读法。

KentRead 是一个 KOReader AI 阅读插件。在原书旁边生成全书介绍，把正在读的章节换一种方式讲，或选中陌生概念，让 AI 结合上下文解释，或联网搜索。

不是离开阅读器去和 AI 聊天，而是在读到有需要的地方时，打开另一种读法，随时回到原文。

- **先看脉络**：用全书介绍了解这本书讲什么、各部分怎样联系。
- **按需改写**：按章节选择阅读效果，以名家的表达技法为参照。
- **划词解释**：选中词句，结合前后原文，让模型解释它在这里的意思。
- **联网搜索**：选中文字后调用 DeepSeek Search，查看网页摘要与来源链接。
- **等待时看作家写字**：改写开头模型还在思考时，显示所选作家的写作动画。
- **手机扫码配置**：在手机上粘贴 API 密钥，不必在阅读器上输入长串字符。
- **生成一次，反复阅读**：结果跟随书籍保存，不同章节、不同配方互不覆盖。

## 阅读与搜索

### 全书介绍

根据全书正文，生成约 1000–1800 字的中文导读：

- 这本书的核心问题、人物或讨论对象是什么？
- 各部分怎样推进，彼此有什么关系？
- 阅读时值得留意什么，哪些章节适合回看？

介绍中的来源链接可以跳回对应章节。目标是帮助进入原书，不是逐章复述，也不是替代原书。提示词要求小说避免泄露结局和关键反转，但不能保证模型完全遵守。

### 章节改写

默认选择当前正在阅读的目录章节，也可以手动选择其他章节。

改写弹窗里点「换个读法」，可在同一章的不同配方之间切换，已生成的配方直接打开。

**先选想要的效果，再用名家的表达技法对齐提示词：**

| 阅读配方 | 适合什么时候用 | 表达方式 |
| --- | --- | --- |
| **更好懂 · 费曼** | 术语多、推理跳跃，读起来费劲 | 直白表达、具体类比、拆开推理 |
| **更诙谐 · 老舍** | 想换一种轻松些的讲法 | 生活化语言、细节观察、温和幽默 |
| **更简练 · 海明威** | 表达冗长，想读得更干净 | 短句、具体动词、少修饰，保留必要信息 |
| **讲成故事 · 茨威格** | 历史、传记、商业书，概念多而人物少 | 回到具体的人和场景，抓住关键时刻 |
| **问答体 · 柏拉图** | 理论、哲学、教材，推理一环扣一环 | 一问一答，用追问亮出推理 |
| **更犀利 · 王小波** | 社科、观点类，想看清论证要害 | 平实口语、清楚逻辑、冷静反讽 |
| **更有画面 · 汪曾祺** | 小说、散文，想读出场景和细节 | 白描、具体细节、从容节奏 |
| **说书腔 · 单田芳** | 小说、历史，想换成听书的感觉 | 说书人口吻、埋扣子、留悬念 |
| **武侠风 · 金庸** | 小说、历史，想读得更有气势 | 半文半白、人物出场有气度 |
| **讲给孩子 · 郑渊洁** | 难书入门、亲子共读 | 短句、生活经验、具体例子 |

改写先提其骨，再补其肉：先理出本章的主线、关键节点和必须保留的事实，再按配方技法重新讲一遍，细节优先取自原文，而不是逐句替换词语。

「更简练」不是摘要：目标是压缩表达，而不是删除关键情节或论据。所有改写提示词都要求保留事实、人物关系、数据和限定条件，并标明新增的辅助说明。

人名只是技法参照，不代表作品由其本人创作或认可。**改写是 AI 辅助读本，可能遗漏或误解内容，仍需对照原文核查。**

### 划词解释 · AI

选中词句后点击 **AI 解释**，有两个入口：划词操作菜单，或单词长按打开的词典弹窗（需要支持词典按钮扩展的较新 KOReader，旧版请拖选文字走划词菜单）。主菜单里没有对应项。

- 发送选中文字、前后各约 300 字原文（英文约 150 词）、书名、作者和当前章节标题到你配置的模型服务。选中超过 1000 字会被拒绝。
- PDF 等固定页面文档只发送选中文字，没有前后原文。
- 使用主模型配置，包括思考模式。思考强度高时可能要等几十秒，等待时可以展开查看思考过程。
- 结果按「书籍 × 选中文字」保存。在别处选中同样的文字，会直接打开已保存的解释；点 **重新解释** 则用新位置的上下文重新生成。
- 提示词要求区分「上下文能看出的」和「一般知识」，并避免剧透，但不能保证模型完全遵守。解释可能不准确，请对照原文。

### 联网搜索 · DeepSeek Search

选中词句后点击 **联网搜索**，有两个入口：划词操作菜单，或单词长按打开的词典弹窗（需要支持词典按钮扩展的较新 KOReader，旧版请拖选文字走划词菜单）。

1. 编辑或确认搜索词，最多 **128 个 Unicode 字符**，支持 `site:`、引号等官方搜索语法。
2. 点击 **联网搜索**，直接调用官方 `POST https://api.deepseek.com/v1/tools/search`。
3. 弹窗显示前 5 条结果的标题、摘要、站点和发布时间（如有）。点击来源链接，可使用 KOReader 的外链菜单复制、显示二维码或在支持的设备上打开浏览器。

这里只调用 **Search 接口**，不把结果再交给聊天模型，不生成 AI 综合答案，也不额外调用 Fetch 抓取网页。请求不发送全书、章节、书名或作者，只发送输入框中的搜索词和结果选项。

结果按「书籍 × 搜索词」保存，并标注设备上的搜索时间。再次输入同一搜索词，点击 **已保存结果** 可离线阅读；点击 **联网搜索** 或 **重新搜索** 会发起新请求，不会自动以旧缓存代替搜索。

Search 按官方规则计费，和聊天模型的 token 费用不同；具体以 [DeepSeek 搜索文档](https://api-docs.deepseek.com/zh-cn/guides/search/) 为准。错误不会自动重试，避免意外重复调用。

### 写作动画

改写开始、正文还没出来时，弹窗里不显示思考片段，而是播放所选作家的定格动画：海明威和王小波在打字机上打字，老舍、费曼、茨威格等人提笔写字，单田芳在说书。展开「思考」即可切回思考过程；正文开始后自动切换为正文。

动画用 `art/` 里的 30 张灰度图（每位作家三张：静止、动作 A、动作 B），每 0.25 秒只重画局部并全程使用 E Ink 的快速刷新，避免闪屏。图片是 AI 生成的示意插画，人物形象仅为风格示意，不代表本人，与其本人及家属无关。

## 快速开始

### 1. 安装插件

将本项目目录复制到阅读器的：

```text
koreader/plugins/kentread.koplugin/
```

保留全部 Lua 文件、`setup.html` 和 `art/` 目录，确保 `main.lua`、`_meta.lua` 直接位于上述目录内，然后重启 KOReader。

### 2. 手机扫码配置

准备一个设备能够访问的 **OpenAI 兼容接口**、模型名称和自己的 API 密钥。

1. 手机和阅读器连接同一个可信 Wi-Fi。
2. 在 KOReader 中打开一本可重排的文字书。
3. 进入 **菜单 → 工具 → KentRead → 扫码配置接口 / 密钥**。
4. 手机扫码打开临时页面，填写接口地址、模型名称和 API 密钥。
5. 点击「保存到阅读器」，看到成功提示后即可关闭网页。

接口地址填写服务根地址，不要包含末尾的 `/chat/completions`：

| 接口 | 地址示例 | 模型名称 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | 当前示例配置为 `deepseek-flash`，请以服务商实际支持为准 |
| OpenAI | `https://api.openai.com/v1` | 填写账号可用的模型名称 |
| 其他兼容服务 | 服务商提供的兼容接口根地址 | 填写对应服务支持的名称 |

联网搜索的密钥配置：

- 主接口为官方 `https://api.deepseek.com` 或 `https://api.deepseek.com/v1` 时，可直接复用主 API 密钥。
- 主接口为其他服务时，在扫码页展开 **联网搜索 · DeepSeek（可选）**，单独填写 **DeepSeek 搜索 API 密钥**。不会把其他服务商的主密钥发送给 DeepSeek。
- 已单独填写搜索密钥时优先使用它；留空保留原值。搜索接口地址固定为官方地址，不跟随主模型接口变化。

**扫码页面使用未加密的局域网 HTTP，仅在可信网络使用。** 不经过插件开发者的服务器，但同一网络上的传输仍有被监听的风险；公共 Wi-Fi 下请改用 USB 配置。二维码包含临时访问凭据，请勿分享。

保存、手动关闭或 5 分钟超时后，配网服务关闭；休眠、断网、关书和退出时也会关闭。页面不会回显已有密钥，留空可以保留旧密钥；更换接口地址时必须重新填写密钥。

### 3. 开始阅读

进入 **菜单 → 工具 → KentRead**（位于工具菜单最前）：

- **全书介绍**：没有缓存时确认生成，已有结果直接打开。
- **章节改写**：选择一种阅读配方；想处理其他章节，点「选择其他章节」。
- **查看生成进度**：重新打开正在生成的内容。
- **停止生成**：取消当前任务，不删除之前保存的正文。

导读与改写的正文流式接收、逐步刷新，可展开思考过程；搜索等待接口返回完整结果后展示。关闭弹窗后任务继续，完成时提示；关闭这本书则取消任务。同一时间运行一个生成或搜索任务，但可以阅读其他已缓存版本。

弹窗内支持调整字号、钉住页面和重新生成。章节改写还提供「查看原文」和「换个读法」；跳回原书后，可以用 KOReader 的返回功能回到跳转前的位置。

手势管理中可绑定 **KentRead：全书介绍**、**KentRead：章节改写**。

## USB 配置与高级参数

不使用扫码也可以配置：将 [`config.sample.lua`](config.sample.lua) 复制为 `config.lua`，在电脑上填写后，通过 USB 放回插件目录。

| 参数 | 用途 |
| --- | --- |
| `base_url` | OpenAI 兼容接口根地址 |
| `api_key` | 自己的 API 密钥 |
| `model` | 接口支持的模型名称 |
| `search_api_key` | 可选的独立 DeepSeek 搜索密钥；未填写时仅允许复用官方 DeepSeek 主密钥 |
| `max_tokens` | 模型输出上限，不能超过服务商支持的值 |
| `extra` | 原样并入请求体的附加参数，例如思考模式配置 |

示例默认使用 DeepSeek；换其他服务时，请检查 `max_tokens`，并删除不兼容的 `extra` 参数。`model`、`max_tokens` 和 `extra` 不参与 Search 请求。

配置优先级：

- **地址、密钥、模型及独立搜索密钥**：扫码保存的配置优先于 `config.lua`；没有 `config.lua` 时使用示例配置。
- **高级参数**：仍从 `config.lua`（没有则从示例）读取；扫码配置的接口地址与文件配置不同时，不继承原接口的 `extra`。

扫码配置保存在 KOReader 设置目录的 `kentread.json`。若要完全恢复 USB 配置，删除此文件即可。`config.lua` 已被 Git 忽略，**请勿提交真实密钥**。

## 隐私与费用

- **全书介绍发送全书正文；章节改写只发送选中章节正文**，附带书名和作者。父章节包含其子节；没有目录时退回「全文」，请留意生成确认提示。
- **划词解释发送选中文字、前后各约 300 字原文、书名、作者和当前章节标题**到你配置的模型服务，不经由插件开发者的服务器。
- **联网搜索仅发送确认后的搜索词到官方 DeepSeek Search**，不附带原文上下文。搜索词可能包含你选中的原文片段，请在提交前确认。
- 书籍资料直接发送给你配置的模型服务，不经由插件开发者的服务器。服务商可能记录内容并收取费用，请自行确认其政策及使用权限。
- 配网页面不加载第三方脚本或资源，已有密钥不会返回给浏览器。
- 密钥以明文保存在设备设置目录，不是加密存储。写入时设置 `0600` 权限，但某些设备文件系统不支持 Unix 权限；备份或分享设置文件前请移除密钥。
- 生成结果、思考过程、搜索词和网页摘要也会保存到设备。分享书籍的 `.sdr` 目录时，请注意其中可能包含原书内容、AI 改写内容或搜索记录。

## 数据与兼容

设备上若有旧版浓缩留下的 `condensed.html` 和 `fig*.svg`，现在不再读取，可手动删除。

结果跟随书籍保存在 `.sdr/kentread/` 下：

```text
intro/content.html                   全书介绍
chapters/0001/clear/content.html      第一个目录章节 · 更好懂
chapters/0001/humor/content.html      第一个目录章节 · 更诙谐
chapters/0001/concise/content.html    第一个目录章节 · 更简练
search/<搜索词的 SHA-256>/content.html  对应搜索词的结果
explain/<选中文字的 SHA-256>/content.html  对应文字的 AI 解释
```

导读、改写与 AI 解释各自目录中的 `thinking.txt` 保存思考过程。章节缓存按目录顺序编号，更换原书或修改目录结构后，应重新生成对应结果。

## 支持范围与已知限制

- 全书介绍和章节改写支持 KOReader 可重排的文字书，如 EPUB、AZW3、MOBI、FB2、TXT；不支持 PDF 等固定页面文档。划词解释和联网搜索不依赖全书提取，可用于能够选中文字的 PDF，但 PDF 上划词解释没有前后原文。
- **只在 Kindle PaperWhite 3 上做过真机验证。** 代码里有 Kindle 专用部分（`lipc-set-prop` 防休眠、`iptables` 临时开放配网端口，写作动画的刷新方式也按它的 REAGL 屏调过）；其他 Kindle、Kobo 等设备未验证，欢迎反馈。
- 当前生成实现调用设备上的 `/usr/bin/curl`，设备还需要能够访问所选模型接口。
- 全书介绍整本一次发送。本地正文安全上限为 3 MB，实际还受模型上下文限制，不代表所有模型都能容纳这么多内容。
- 章节按书内目录划分，父章节包含子节，范围截止到下一个同级或上级目录项；没有目录时将全文作为一个章节。
- 章节改写可能比摘要更长。达到模型输出上限时会标记「可能不完整」，可调整 `max_tokens` 或选择更小的子节。
- 尚无自动分块、断点续写或网页配方管理；失败后重新生成可能再次产生费用。
- 自动化测试不等于设备兼容性验证；Kindle 的排版、二维码辨识度及临时防火墙处理仍需真机验证。

## 常见问题

**找不到 KentRead 菜单？** 先打开一本书，插件只在阅读界面加载。再检查安装目录是否多嵌套了一层，并重启 KOReader。

**没有二维码？** 当前 KOReader 可能缺少 `QRWidget` 组件。升级 KOReader，或在手机浏览器手动输入弹窗中的完整临时网址。

**手机打不开配网页面？** 确认两台设备连接同一 Wi-Fi，且页面尚未关闭或超时。访客网络、客户端隔离和网络访问限制可能阻止连接；当前配网需要局域网 IPv4。无法连接时可用 USB 配置。

**划词菜单里没有联网搜索或 AI 解释？** 单词长按会直接打开词典：较新的 KOReader 里，按钮在词典弹窗中（Wikipedia 弹窗不显示）；否则请拖选文字打开划词菜单。旧版 KOReader 若缺少划词菜单扩展接口，请升级。联网搜索和 AI 解释都没有主菜单入口。

**搜索提示密钥或余额问题？** Search 使用 DeepSeek API 密钥，不接受其他模型服务商的密钥。检查单独的搜索密钥是否有效；HTTP 402 表示余额不足，429 表示限速，请按提示处理后手动重试。

**接口报错或正文不完整？** 检查密钥、接口地址、模型名称，以及 `max_tokens`、`extra` 是否受该模型支持。较小上下文模型不适合整本导读；较长章节可尝试选择子节。停止或失败不会删除之前保存的正文。

## 开发与测试

内置配方和提示词位于 [`kr_prompts.lua`](kr_prompts.lua)。新增章节配方时，在 `STYLES` 中提供唯一的 `id`、`title`、`author`、`description` 和 `techniques`，重启 KOReader 后会出现在选择界面。`id` 用于缓存路径，已发布的配方应保持稳定。

搜索词校验、安全的结果渲染和缓存 ID 位于 [`kr_search.lua`](kr_search.lua)；选中文字校验、上下文裁剪、发给模型的消息和缓存 ID 位于 [`kr_explain.lua`](kr_explain.lua)；普通 JSON 工具请求与聊天流式请求共用 [`kr_llm.lua`](kr_llm.lua) 的后台 curl 传输，但不混用响应格式。

不需要 KOReader 或真实 API 密钥即可运行自动化测试：

```sh
uv run --with lupa python tests/run.py
```

测试使用 Lua 5.1 执行插件代码，替代 KOReader UI 和后台进程，覆盖章节范围、配方缓存隔离、搜索词 Unicode 限制、密钥隔离、来源链接安全、JSON 搜索响应、HTTP 分包及访问限制、SSE 和配网生命周期。另通过 Python 的 LuaSocket 适配层完成真实 TCP 的 GET/POST、UTF-8 表单与保存关闭测试。
